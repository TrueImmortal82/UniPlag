## 🌟 Обзор платформы

**UniPlag & ICG** — комплексная платформа нового поколения для университетов, диссертационных советов и научных издательств. Система выходит далеко за рамки классического синтаксического поиска текстовых совпадений, решая две главные проблемы современного образования: **машинную генерацию текста нейросетями (LLM)** и **пассивную компиляцию чужих источников без собственного интеллектуального вклада автора**.

Платформа оценивает не только совпадение строк, но и **эпистемическую структуру работы** — глубину синтеза цитируемых источников, аргументированность авторских выводов и смысловую связность рассуждений.

## 🎯 Ключевые возможности

### 1. 📊 Комплексный 4-Метрический анализ
Каждая студенческая или научная работа оценивается по 4 независимым векторам:
* **Текстовая оригинальность** (0–100%) — уникальность авторского текста относительно локального и глобального корпусов.
* **Заимствования и цитирования** (0–100%) — детальная классификация совпадений с фрагментарной подсветкой первоисточников.
* **Вероятность машинной генерации (AI-детекция)** — многофакторный анализ стилометрии, связок и синтаксической однородности.
* **Индекс интеллектуального вклада (ICG v0.4)** — оценка глубины синтеза концепций, самостоятельности логических заключений и разрешения научных противоречий.

### 2. 📜 Официальные академические PDF-справки с 512-битной печатью
* Формирование официального векторного сертификата (формат А4) для Государственной экзаменационной комиссии (ГЭК), диссертационных советов и деканатов.
* **512-битная цифровая печать подлинности (SHA-512)**, защищающая справку от подделки, модификации оценок или перестановки фамилий.
* Мгновенная онлайн-проверка подлинности любого выданного сертификата через постоянную ссылку `/verify/{seal}`.

### 3. 🌐 Мультиязычный интерфейс и международная сертификация
* Бесшовное переключение интерфейса **`🇷🇺 RU`** и **`🇬🇧 EN`** в один клик.
* Двуязычная выгрузка официальных сертификатов:
  * На русском: *«Официальная справка о результатах проверки ВКР и научных работ»*;
  * На английском: *«Official Academic Verification Certificate of Thesis Originality & ICG Synthesis»*.

### 4. 🏆 Рейтинг кафедры (TeacherScore) и лиги успеваемости студентов
* **Педагогический индекс кафедры**: аналитика результативности научных руководителей, динамика успеваемости подопечных и качество курируемых работ.
* **Студенческие лиги успеваемости**:
  * 🟢 **Высшая лига (Top Tier)** — работы с высоким уровнем самостоятельного синтеза и низким процентом заимствований.
  * 🟡 **Средний эшелон (Standard Tier)** — допустимые работы, требующие точечного усиления выводов.
  * 🔴 **Зона академического риска (At Risk)** — компилятивные или машинно-сгенерированные работы, требующие глубокой переработки.

### 5. 📚 Интеграция с открытыми научными репозиториями (arXiv)
* Встроенный модуль поиска по мировым репозиториям научных публикаций (arXiv Open API).
* Добавление эталонных научных статей в университетский корпус проверок в 1 клик.

### 6. 🔒 Защищённый формат поставки BlackBox (`.bbx`)
* Поставка всей демонстрационной версии в виде **единого зашифрованного контейнера (AES-256-GCM)** с 512-битной цифровой подписью.
* **Исполнение строго в оперативной памяти (Zero-Disk Footprint)**: байткод и ресурсы монтируются в виртуальную память без записи на диск, что делает невозможной декомпиляцию исходного кода.
* Встроенный анти-отладочный контур для защиты коммерческой тайны и алгоритмических ноу-хау.

## 🤖 Локальный нейросетевой контур (Ollama) и автозагрузка моделей

Для максимальной точности глубокого смыслового анализа и детекции текста языковых моделей (LLM) системе **требуется установленная Ollama**:

1. **Установка Ollama**: скачайте и установите с официального сайта [**https://ollama.com**](https://ollama.com) (Windows / Linux / macOS).
2. **Автоматическая подготовка моделей**:
   * UniPlag **автоматически обнаруживает запущенную Ollama** и при первом старте (включая демо-режим и защищённый контейнер BlackBox) **самостоятельно подгружает оптимальную модель** (`qwen2.5:1.5b` / `llama3.2` / `gemma4`).
   * Ручная загрузка (опционально):
     ```bash
     ollama pull qwen2.5:1.5b
     ```
3. **Автономность**: если Ollama временно недоступна, платформа автоматически переключается на встроенный высокоскоростной ML-ансамбль стилометрического анализа (TF-IDF + Char N-Grams + Meta-Learner).

## 🚀 Быстрый запуск

### Вариант 1. Запуск из стандартного окружения:
```bash
# 1. Запуск сервера на порту 7932
python run_server.py --port 7932

# 2. Открыть в браузере:
# http://localhost:7932
```

### Вариант 2. Запуск защищённого контейнера BlackBox:
```bash
# 1. Двойной клик по run_blackbox.bat или выполнение команды:
python scripts/run_blackbox.py --port 7932
```
